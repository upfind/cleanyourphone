# CleanYourPhone 📱

> 免 Root、零刷机、**免手动安装 ADB**，基于规则库驱动的 Android 手机一键去广告与系统纯净优化工具。

借鉴 [CleanYourTV](https://github.com/Gathin23/cleanyourtv) 的设计哲学，CleanYourPhone 旨在通过全自动脚本与 AI 协同，解决智能手机系统中泛滥的开机广告、负一屏资讯、锁屏壁纸营销以及第三方 App 恶劣的“摇一摇”流氓开屏跳转。

---

## ✨ 核心特性

- **⚡ 零环境门槛（小白友好）**：
  - **无需手动安装 ADB**：电脑上有 `adb` 自动使用；没有 `adb` 时，脚本/AI 会自动从 Google 官方直链秒速拉取免安装运行环境（约 10MB），**用户完全不需要手动配置环境变量**。
- **🛡️ 纯净安全，100% 可逆**：
  - **免 Root**：仅需开启手机的 USB 调试；
  - **停用而非卸载**：使用 `pm disable-user --user 0` 冻结系统服务，不修改系统分区，不影响系统 OTA 升级；
  - **自动状态快照**：操作前自动备份原始状态，通过 `tools/restore.sh` 随时一键原样复原。
- **🚀 三层立体去广告策略**（首发支持小米 MIUI / HyperOS）：
  1. **系统级臃肿与广告服务清理（Debloat）**：一键停用 MSA（系统广告分发中心）、Analytics 数据收集、锁屏画报、快应用等流氓常驻服务；
  2. **系统设置级广告关闭（Settings Tweaks）**：批量写入底层系统设置，关闭个性化广告推荐与 OAID 追踪，并注入全局 AdGuard DoT 加密去广告 DNS；
  3. **“摇一摇”流氓跳转彻底封杀（Sensor Blocker）**：通过 Android 原生 `appops` 精准限制微信、淘宝、知乎、微博、B站等常见 App 获取加速度计/陀螺仪数据，在不影响 App 正常使用的前提下终结“手抖即跳转广告”。
- **🤖 完美支持 AI 协作**：
  - 内置 [`PROMPT.md`](PROMPT.md)，将手机连上电脑后，直接把提示词发给 AI 助手（Claude Code、Cursor、Gemini CLI 等），Agent 会全自动准备环境、探测、备份、执行并生成报告。

## 🚀 快速开始

### 准备工作（仅需 1 步）
- **手机开启 USB 调试**（以小米 / Redmi 为例）：
  1. 打开「设置 → 我的设备 → 全部参数与信息」，连续点击「OS 版本」或「MIUI 版本」7 次，开启开发者模式；
  2. 返回「设置 → 更多设置 → 开发者选项」，开启 **USB 调试**；
  3. 用数据线将手机连接电脑，在手机屏幕弹出的授权弹窗中勾选“始终允许”并点确定。
  *(电脑端不需要提前下载或配置任何调试工具！)*

---

### 方式一：让 AI Agent 帮你跑（最省心）

直接将 [`PROMPT.md`](PROMPT.md) 中的提示词复制发给你的 AI 编程助手（如 Claude Code、Cursor、Gemini CLI），Agent 将全自动完成环境就绪、连接探测、安全备份、分批清理和效果汇报。

---

### 方式二：手动极速执行

在终端中进入项目目录，直接运行主脚本（若电脑未配置 ADB，会自动为你准备）：

```bash
# 1. 探测已连接设备信息
python3 tools/phone.py --probe

# 2. 执行一键清理（自动配置环境 -> 创建备份 -> 停用广告服务 -> 优化设置 -> 屏蔽摇一摇）
tools/clean.sh
```

## 🔄 如何一键恢复？（后悔药）

如果你打算换机、售后保修，或者某些功能你想要找回，随时可以无损复原：

```bash
tools/restore.sh
```
恢复脚本会做三件事：
1. 从 `backup/` 中读取最近一次操作的快照，把停用的所有系统包重新 `enable` 恢复；
2. 将全局 Private DNS 模式与个性化广告开关恢复为系统默认；
3. 将第三方 App 的传感器访问权限重新放开（`allow`）。

## 🛡️ 安全底线说明

本项目遵循严格的白名单与安全底线：
- **绝对不触碰**：手机通话短信通信（RIL）、微信/支付宝指纹与安全支付环境、NFC 交通卡门禁、系统安全中心核心、小米官方服务推送框架（xmsf）。
- **零卸载**：所有系统包全部使用用户级停用（`pm disable-user --user 0`），绝不调用破坏性的 `pm uninstall`。
